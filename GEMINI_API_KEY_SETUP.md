# How to Fix Your Gemini API Key Issue

## Problem
Your current API key starts with `AQ.A` which is **not a valid Gemini API key format**. Gemini API keys must start with `AIza`.

## Solution: Get a Valid Gemini API Key

### Step 1: Visit Google AI Studio
Go to: https://aistudio.google.com/app/apikey

### Step 2: Create or Get Your API Key
1. Sign in with your Google account
2. Click "Create API Key" or "Get API Key"
3. Copy the key (it should start with `AIza`)

### Step 3: Add the Key to Tocky Code

**Option A: Using VS Code Extension (Recommended)**
1. Open VS Code
2. Click the Tocky Code icon in the sidebar (shield icon)
3. Click the "🔑" (Configure API Key) button
4. Select "Google Gemini" as the provider
5. Paste your API key (starts with `AIza`)
6. Click "Save API Key"

**Option B: Manually Edit .env File**
1. Open `E:\Miniproject\.env`
2. Replace the current line:
   ```
   GEMINI_API_KEY=your_gemini_api_key_here
   ```
   with:
   ```
   GEMINI_API_KEY=AIzaSy... (your actual key here)
   ```
3. Save the file
4. Restart VS Code

### Step 4: Test the Fix
1. Scan your code for vulnerabilities
2. Click "Propose Fix" on any finding
3. You should now see: "GEMINI used X tokens for this fix proposal"

## How to Verify It's Working

When the Gemini API is working correctly:
- ✅ The fix explanation will say it was generated by Gemini
- ✅ Token usage will be reported
- ✅ You'll see "GEMINI used X tokens" in the notification

When it's NOT working (using fallback):
- ❌ The explanation will say "(Fallback to CodeGuard specialized model: ...)"
- ❌ You'll see a warning about invalid API key format
- ❌ It uses the built-in model instead of Gemini

## Important Notes

- **Free Tier**: Gemini offers a free tier with generous limits
- **API Key Format**: Must start with `AIza` (not `AQ.A` or anything else)
- **Security**: Never commit your `.env` file with real API keys to Git
- **Validation**: The extension now validates your API key format and shows helpful error messages

## Alternative: Use Built-in Model

If you don't want to use Gemini, you can use the built-in fast security model:

1. Open VS Code Settings (Ctrl+,)
2. Search for "Tocky Code"
3. Set "Codeguard: Llm Provider" to `codeguard-model`
4. No API key needed!

The built-in model is fast and works offline, but Gemini may provide more sophisticated fixes for complex vulnerabilities.
